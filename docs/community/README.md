# Comunidade AntiSpam BR — visão geral

Kit para lançar as comunidades oficiais do AntiSpam BR (bloqueador de ligações de spam e golpes, Android, privacidade em primeiro lugar). Tudo aqui é documento: nenhum servidor, grupo ou bot foi criado. Um humano executa os checklists.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `discord.md` | Blueprint do servidor Discord + checklist de cliques |
| `telegram.md` | Canal de avisos + grupo de discussão + checklist de cliques |
| `mensagens-prontas.md` | Textos prontos para copiar e colar |

## Objetivo da comunidade

1. **Suporte**: ajudar quem tem dúvida ou problema com o app.
2. **Denúncias de golpes**: receber relatos de números, scripts e golpes, sem expor dados pessoais.
3. **Feedback**: sugestões e bugs que alimentam o roadmap.
4. **Avisos de campanhas ativas**: alertar rápido quando uma onda de golpe estiver em circulação.

## Tom de voz

- Português do Brasil, direto, simples e acolhedor. Sem jargão.
- Calmo e sem alarmismo: informar, não assustar.
- Honesto sobre limites: o app reduz o spam, não promete bloqueio de 100%.
- Privacidade em primeiro lugar: pedir o mínimo de informação, sempre.

## O que NUNCA postar (vale para equipe e membros)

- Dados pessoais de terceiros: nome, CPF, endereço, foto, prints de conversas com pessoas identificáveis.
- Número completo de pessoa física. Para golpes, mascarar: `(11) 9XXXX-1234`. Números de empresas/robôs de telemarketing podem ser citados se claramente comerciais.
- Links encurtados (bit.ly, tinyurl etc.) ou qualquer link suspeito clicável. Escrever como `hxxp://exemplo[.]com`.
- Pedidos de pagamento, Pix, doação ou venda de qualquer coisa.
- Pedidos de senha, código SMS, token ou dados de cartão.
- Divulgação de outros grupos, apps ou convites.

## Regra de ouro anti-golpe

A equipe **nunca** pede senha, código SMS ou Pix. Mensagem privada (DM) não é suporte oficial. O único e-mail oficial é [EMAIL_SUPORTE].

## Placeholders a preencher

`[LINK_PLAY_STORE]`, `[LINK_DISCORD]`, `[LINK_TELEGRAM]`, `[EMAIL_SUPORTE]`. Procure por colchetes antes de publicar qualquer texto.

## Ordem sugerida de lançamento

1. Discord (blueprint em `discord.md`), 2. Telegram (`telegram.md`), 3. colocar os links no app/ficha da Play, 4. publicar o anúncio de `mensagens-prontas.md`.
